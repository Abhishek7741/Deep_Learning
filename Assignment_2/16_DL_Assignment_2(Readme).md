# MLP Iris Flower Classification

##  Overview

This practical implements a Multi-Layer Perceptron (MLP) neural network for classification of the Iris flower dataset.

The model classifies Iris flowers into three different species based on their sepal and petal measurements.

---

##  Objective

The main objectives of this practical are:

- Load and preprocess the Iris dataset.
- Separate input features and target labels.
- Split the dataset into training and testing sets.
- Build an MLP classification model.
- Train the neural network.
- Evaluate the model performance.
- Visualize the training and classification results.

---

## 📊 Dataset

The practical uses the Iris dataset.

The dataset contains four features:

| Feature | Description |
|---------|-------------|
| Sepal Length | Length of the sepal |
| Sepal Width | Width of the sepal |
| Petal Length | Length of the petal |
| Petal Width | Width of the petal |

### Classes

| Label | Species |
|------:|---------|
| 0 | Setosa |
| 1 | Versicolor |
| 2 | Virginica |
